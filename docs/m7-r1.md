## 1. Design

### 1.1 Program ABI (the design's 3.2-3.3, as built)

```wgsl
struct SpecularLobe { normal:vec3<f32>, alpha:f32, weight:f32 };   // engine API
fn reflection_lobe(s:Surface, input:SurfaceInput) -> SpecularLobe   // optional program hook
fn specular_incident(input:SurfaceInput) -> vec4<f32>               // engine input
```

- `reflection_lobe` is GGX-shaped, as Islam accepted (design 3.4, constraint 1). `alpha` is perceptual roughness squared; `weight > 0` requests rays.
- **`specular_incident` returns `vec4`, not the design's `vec3`.** rgb is the mean exposed radiance arriving over the lobe; w is the traced fraction. The fraction lets a program blend the traced value against its own untraced estimate, so the roughness cutoff fades over 0.35-0.5 instead of switching. A `vec3` with zero meaning "untraced" could not tell untraced from traced black.
  - w = 1 below roughness 0.35, falling linearly to 0 at 0.5.
  - w = 0 on raster, visibility-buffer and cell stages, on non-RT devices, and at the reflection hits themselves (one bounce).
- **The standard program** declares `SpecularLobe(s.n, rough², 1)` and replaces its sky specular with `traced.rgb * (F0 A + B)` by w (the split-sum DFG factor over the lobe's mean incident radiance). Outside the band its ES1 path is untouched.
- **Programs that name neither hook nor input get no reflection text at all**, so their modules are byte-identical to main's (CPU test `reflection_composition_contract`). A program with only one of the two gets a zero stub and traces nothing.

### 1.2 Engine trace (`shaders/reflections.wgsl`)

`src/program.rs` composes the block into traced shading modules whose head declares a shadow TLAS (`hardware_scene` for Hard shading, `fresh_scene` for Soft/Interactive and T1a film shading), and hooks the generated traced entry once, between `surface` and `shade`:

1. `reflection_lobe(s, input)`. Skip outside the band, at `weight <= 0`, or when the lobe normal faces away from the view.
2. Rays leave from the primary receiver point, offset by its exact epsilon on the viewed side of its geometric plane.
   - **Mirror** (rough < 0.05): one ray along `reflect(-v, n)`.
   - **Glossy**: four GGX visible-normal samples on fixed equal-probability radial strata. The azimuth is rotated per pixel by a hash; TR1 frames also turn it by TR1's frame rotation word (`PrimaryFrame.sided.y`, 0 otherwise), so TR1 integrates the strata over frames. No reservoir, resampling, history or denoiser.
   - Samples below the receiver's plane are dropped; if all are, the pixel stays untraced.
3. **Escaped rays** read the environment prefiltered over their sub-cone (`alpha / sqrt(K)` for glossy, sharp for mirror).
4. **Hits** are reconstructed exactly as camera hits, from the TLAS record `(placement+1, primitive, barycentrics)` (`rl_hit_input`):
   - the eye is the reflection origin, so the program sees view vector −d;
   - the uv and normal footprints are ray-cone differentials through `primary_gradients`: the pixel's footprint at the receiver, spreading by the pixel angle, twice the normal's change across the pixel, and twice the sub-cone alpha;
   - the hit's `surface()` and `shade()` run with its own material parameters, and the receiver's are restored afterwards;
   - **the hit's indirect inputs read the open environment.** The entry sets the cache-off state (`rl_indirect_open`) before the receiver's `surface`, traces, and only then prepares the receiver's own cache lookup (`rl_indirect_prepare`) for its `shade`.
   - **Why the open environment at hits:** the first version prepared a cache lookup at each hit and restored the receiver's afterwards. Section 4 measures its cost: +0.62 ms of quarry shading with the cache on, on a scene that traces no reflection rays.
   - **Constraints this records:** reflection hits never see the cache's sky occlusion or bounce, and in reflecting modules a program's `surface()` reads the open environment from the indirect inputs. Its `shade()` still reads the prepared values.
5. **Light visibility at a hit** is one hard ray toward the light on the frame's TLAS (`rl_hit_shadow`), because the frame's visibility inputs (Interactive counts, Exact epsilons) belong to camera receivers. This is substituted into `light_visibility` only while a hit is being shaded, and only in these modules.

**One program per traced frame.** Traced admission already rejects mixed-program frames (`primary_ray_gpu.rs admit_draws`), so the program shading a pixel is also every hit's program, and "each hit shaded by its own program" holds by construction. Mixed-program frames need per-program hit dispatch: recorded gap.

**Bindings.** The Soft and T1a film shading layouts gain the shared TLAS at group 0 binding 2. Hard shading already had it. Non-RT layouts filter acceleration structures out, as before. There are no new buffers, textures, group-3 bindings or storage buffers (DC1 owns lighting binding 21).

## 7. Claim notes (engineering reading, not clearance)

- **US 12,051,145 (Adshir/Snap).** Each pixel's rays start at its own traced primary hit and write only its own value. There is no common projection, grouping, matching or reassignment, so the claim's decoupling, (c) and (d) are absent (P0's C7). Traced primaries are not the operative avoidance.
- **US 11,315,310 and the ReSTIR family.** Glossy sampling uses fixed stratified VNDF quadrature, with no reservoir, resampling, prior selections or spatial reuse (C1). Hit shading calls the program's `indirect_*` inputs, which read the world radiance cache when it runs. The cache is read, never written, and nothing resamples.
- **US 10,116,916, SVGF and the history-clamp family.** No denoiser, variance statistic or history. The only temporal integration is TR1's, which R1 feeds as an ordinary shaded sample. R1 reads TR1's frame rotation word, an engine frame index, and none of TR1's outputs (W5 unchanged).
- **Planar-view patents (US 10,565,776 / 10,789,759)** are not reached: there are no planar views.
- No Epic, NVIDIA SDK or third-party shader code was copied. VNDF sampling follows Heitz 2018 and the orthonormal basis Duff et al. 2017, written from the papers.
