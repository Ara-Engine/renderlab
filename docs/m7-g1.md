# M7-G1: world radiance cache, sky visibility

Unit G1 of [the M7 design](m7-design.md) (draft 2.2), branch `t3/m7-g1` on main `708e87c` (M7-U0 merged). Contract: [milestone-7.md](milestone-7.md). Claim constraints: [m7-p0-claims.md](m7-p0-claims.md) W1-W3, C1-C5 and C8. Labels: **M** measured here, **A** author-reported elsewhere, **I** inference.

## Design as built

**Code.** `src/gi_cache.rs` (state, settings, passes, profiling), `src/gi_bvh.rs` (non-RT geometry), `shaders/gi_cells.wgsl` (keys, slots, SH), `shaders/gi_cache.wgsl` (kernels), `shaders/gi_rays_hardware.wgsl` and `shaders/gi_rays_software.wgsl` (the two ray sources), `shaders/gi_api.wgsl` (the program input). The cache code is copied from the N8o surface-cache pattern into these new files; no shadow file is shared or edited (M7 root decision).

**Cells.**
- A cell is a cube of edge `min_edge * 2^level` at integer coordinates `floor(p / edge)`, plus a six-way normal bin: the dominant axis of the receiver's geometric normal on its viewed side. The position is never projected (C2) and cells stay cubic (C3).
- The level is the smallest power-of-two edge at least `cell_pixels` pixels of footprint at the receiver's distance.
- Keys are two independent 32-bit hashes of (level, bin, cube). The first picks an 8-slot bucket, the second the start offset in it.
- A 48-word slot holds: key, state, last-seen frame, cell definition, query point and normal, one visibility bit per fixed direction (up to 128), a known-direction mask, and 27 f32 for the L2 SH of the occluded sky (RGB). **No field counts samples (W1, C8).**

**Fixed query point (W2).** A cell's rays start from a point fixed by its key alone:
- up to five probe rays run along the bin normal through the cube from fixed points on its face, overhanging both faces by 1% of the edge;
- the first hit, in fixed order, is kept if its viewed side faces the bin and lies in the cube;
- a ray from it along its normal must not leave through the inside of a closed surface (a source-back hit);
- if none qualifies, the cell is an orphan and gets no lookup weight.

No pixel votes and nothing is ranked.

**Values (W1).** Each update traces the cell's fixed directions, reduces them in the workgroup in a fixed order, and *replaces* the SH. The directions are a uniform Fibonacci hemisphere about the query normal, optionally rotated about it by an angle the key fixes. The value is a fixed-weight quadrature, `sum v_k L(d_k) 2pi/K Y(d_k)`, with no blend across updates.
- Form 1 (`direction_phases = 1`, the default) traces every direction on each update.
- Form 2 (`direction_phases = S`) keeps each direction's last bit in its slot and re-traces the directions with `k mod S == frame mod S`. Directions not yet traced count as open sky, and the cell is re-queued until all are known.

**Scheduling (W2), with no ranking.**
- Every new cell is traced in the frame it appears.
- Every cell whose cube, or any of whose fixed rays (followed without bound), meets a moved placement's swept bounds is invalidated and traced in that frame.
- A fixed rotation (`rotation_period`) can re-trace `(slot + frame) mod P == 0`. It is off by default: events alone keep sky visibility exact.
- An environment change (map, yaw or constant colour) re-integrates every cell from its stored bits with no rays. Intensity is applied at lookup, so its response lags 0 frames.

**Inserts (C4).** The probe pass finds each pixel's cells, marks them seen, and lists the misses per 8×8 tile, deduplicated in workgroup memory. Each miss picks the first free or evictable slot of its bucket, as the probe left the table, and raises that slot's claim word with `atomicMax`. The highest claim writes the cell; the rest lose and retry next frame. Unseen cells become reusable after `evict_frames`. A camera cut or scene change can clear the table (`reset_indirect`).

**Lookup (W3).**
- `indirect_irradiance(input, n)` reads the cells of the engine receiver (`input.receiver`), never a screen buffer: trilinear over the eight cells around the point (the default), or the containing cell.
- The weights are fixed, there is no jitter, and cells without a value get no weight. When nothing at a level has a value, it reads the parent level, then the open environment.
- It evaluates the SH's clamped-cosine convolution about the program's normal `n`, in lux, unexposed.
- **Robust keys.** The kernels decode the shared hit records through their own geometry tables, so their f32 arithmetic can round differently from the shading module's. Where a point lies within rounding of a cell face, a level boundary or a bin tie, the probe also requests the neighbour. Shading's own key is therefore always present.

**Ray sources.**
- **RT:** hardware ray queries against the renderer's TLAS. Visibility rays are any-hit and unbounded; probe rays are closest-hit with vertex return.
- **Non-RT:** one software BVH4 traversal in R0c's record layout (20-word nodes with quantized byte planes, 8-word leaves), over a flat instance list rebuilt on the CPU when transforms change. Each ray is its own work item from the top, with no per-node hit lists or launches (W8).
  - `set_indirect_geometry` builds a full-detail BVH from a mesh's triangles (`gi_bvh::build`, checked by R0c's own `Bvh::validate`).
  - `set_indirect_bvh` takes a cooked R0c sidecar at one level.
  - Moving casters are per-instance BLASes under their current transforms.

**Passes per frame.** Probe, claim, resolve, scan (event frames only), arguments, trace (indirect, one workgroup per queued cell), integrate (indirect). They run after the primaries' hit records and before shading, on traced (RT) and visibility-buffer (non-RT) frames whose programs call the input.

**Cost for non-callers.** `indirect_irradiance` is composed only into modules whose program names it (`program::uses_indirect`, a comment-aware token check). Other programs' modules are unchanged, and frames whose programs never call it run no cache pass. Lighting group 3 gains binding 20 (one read-only storage buffer; the cache kernels bind a header-only copy there so they never alias the table they write).

**Standard program.** Sky diffuse is `exposed_product(indirect_irradiance(input, n), base*(1-metal)/PI)`. Sky specular is unchanged (unoccluded); `indirect_radiance` belongs to R1 in the design, so G1 does not add it.

**Default.** `IndirectSettings::enabled` is false at this checkpoint, so existing images are unchanged apart from the diffuse term's new product (an f32 rounding difference). Defaults otherwise: trilinear, 4 px cells, 64 directions, no direction rotation, replace-on-update, 2^18 slots, no rotation refresh.
