# Renderlab

Working name for an independent Rust rendering library intended for public use.

Two priorities:

1. A useful rendering product in its own right, with excellent image quality and measured runtime performance.
2. Extremely fast development: immediate scene edits, shader hot reload, fast incremental Rust compilation, and quick scene startup.

This repository currently contains the project bootstrap and research. It does not render yet.
Branding and the public license remain undecided; no remote has been published.

Read [the project brief](docs/brief.md) for the first development milestone and historical evidence.

Checks: `cargo check`, `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`.
